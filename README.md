# ☀️ Summer Countdown

Точный отсчёт времени до лета (и обратно) в реальном времени. Одна страница, ноль зависимостей.

## ✨ Что внутри

- Обратный отсчёт до 1 июня: дни, часы, минуты, секунды
- Когда лето наступает — переключается на отсчёт до конца сезона
- Детальный баланс лета: сколько прошло, сколько осталось
- Таймлайн всех четырёх сезонов
- Чекпоинты: 200, 150, 100, 30, 7 дней до лета и другие
- Светлая и тёмная темы
- Конфетти при наступлении лета
- Адаптивная вёрстка, работает на телефонах
